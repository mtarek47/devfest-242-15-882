## Overview

Tender Document Package Builder is a 100% frontend web application that helps office staff turn a collection of PDF files into a complete, verified, and correctly ordered tender PDF package ready for official submission.

## Setup & How to Run

1. Open `index.html` directly in any modern browser (such as Google Chrome), or
2. Host on any static web server / GitHub Pages:
   ```bash
   python -m http.server 8000
   ```
   and visit `http://localhost:8000`.
